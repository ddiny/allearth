1. 실행 방법
- ZIP을 먼저 '모두 압축 풀기'로 새 폴더에 풉니다. ZIP 안에서 바로 실행하지 마세요.
- Windows: 이 폴더의 START.cmd를 더블클릭합니다.
- macOS 또는 직접 열기: allearth-app-prototype 폴더의 preview.html을 Chrome 또는 Edge에서 엽니다.
- 별도 설치나 실제 계정 로그인 없이 화면 흐름을 확인할 수 있습니다.

2. 먼저 확인할 화면
- v8: 저장 해제 실패 시 카드·탭·스크롤 유지와 재시도, 댓글 초안 보존을 수정했습니다.
- Feed/My/이슈의 댓글에서 최신순·인기순, 답글, 수정·삭제와 실패 재시도를 확인합니다.
- Feed World 작성, 위치 선택 적용/취소, 이미지 오류 격리, 브라우저 뒤로가기 확인을 제공합니다.
- Earth 국가·이슈 통합 검색, 국가 시트 확장/축소, 이슈 좋아요·댓글·저장을 확인합니다.
- 첫 화면: My 프로필. My 그룹에서 격자 / 목록 / 설정 / 시청내역 / 비로그인 화면을 선택합니다.
- My의 게시글 격자 / 게시글 목록은 샘플 게시글 6개를 한 번 추가합니다. 기존 글과 수정·삭제는 유지합니다.
- 왼쪽 로그아웃 예시 뒤 다른 화면을 선택하면 해당 예시의 로그인 상태로 전환합니다. 앱 내부 로그아웃은 로그인 전까지 유지됩니다.
- 하단 Earth / Feed / Saved / My 메뉴를 오가며 저장·프로필·내 글 상태가 유지되는지 확인합니다.
- 글 작성, 이미지 첨부, 수정·삭제, 닉네임 변경, 설정·로그아웃·탈퇴의 모의 흐름을 확인합니다.
- My 작성·수정은 바텀시트, 설정 닉네임 변경은 팝업입니다. 로그아웃·탈퇴 완료 후 로그인 화면으로 이동합니다.
- Saved 그룹에서 국가 / 게시글 예시, 빈 상태와 오류·재시도를 확인합니다. 저장 콘텐츠는 최대 100개입니다.
- Saved 첫 진입 시 이미지 게시글 3개와 국가 3개가 준비됩니다. 기존 저장 콘텐츠가 있으면 그대로 보여주며 저장 해제 후 다시 추가하지 않습니다.
- Saved 국가는 국기와 이름이 세로로 정렬된 3열 카드이며 게시글은 2열입니다. 저장 해제 버튼·본문 크기·320/390/430px 배치를 개선했습니다.
- 국가 시트의 선정 이슈 최대 5개, 현지 시간·편집 예시 안내, 관련·다음 이슈를 확인합니다. Feed 신고는 서버 전송 없는 모의 동작입니다.
- 로그인 / 가입 / 홈 / 이슈 메뉴로 기존 화면도 검토할 수 있습니다.
- 320 / 390 / 430 너비 버튼으로 화면 크기를 바꿔 확인합니다.
- 초기화 버튼은 Feed/My/Saved의 탭 내 공유 샘플 데이터를 초기화합니다.

3. 프로토타입의 동작 범위
- 로그인, 글 작성, 반응, 회원탈퇴는 샘플 동작이며 실제 계정 생성·서버 게시·실제 계정 탈퇴가 아닙니다.
- 지역 Feed의 작성·반응 내용은 같은 브라우저 탭에서만 유지되며 다른 팀원에게 전달되지 않습니다.
- 뉴스와 이미지는 예시이며 실시간 정보가 아닙니다. 출처 링크를 열 때는 인터넷 연결이 필요합니다.
- Rising 운영 임계값이 미설정된 기본 상태에서는 Rising을 숨깁니다. 실시간 집계 서비스는 연결하지 않았습니다.
- 지구본은 브라우저의 WebGL 지원이 필요합니다.
- 로컬 파일 실행이 회사 브라우저 정책으로 제한된다면, Python이 설치된 환경에서
  allearth-app-prototype 폴더를 기준으로 아래 명령을 실행합니다.
  python -m http.server 4173 --bind 127.0.0.1
  접속 주소: http://127.0.0.1:4173/preview.html
