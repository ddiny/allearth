## 매일 돌아가는 흐름

```
00:00 KST  매일 화제 수집 (collect.yml)
             구글 트렌드 → Claude 정리 → Supabase
   ↓ 성공하면 바로
           매일 카드뉴스 만들기 (cards.yml)
             카드 이미지 → Storage 업로드 → 실행 요약에 미리보기
   ↓ 사람이 미리보기를 보고 직접 실행 (= 승인)
           인스타에 올리기 (publish.yml)
             캐러셀 게시 → 올린 기록 저장
```

`인스타에 올리기`는 자동으로 실행되지 않아요. 사람이 Run workflow를 눌러야만 올라가요.

## 처음 한 번 설정

### 1. Supabase
SQL Editor에서 `sql/06_instagram.sql`을 실행해요. 토큰 보관용 표와 게시 기록 표가 만들어져요.
카드 이미지용 Storage 버킷 `cards`는 첫 실행 때 자동으로 만들어져요. 인스타가 이미지를 가져가야 해서 공개 버킷이에요.

### 2. 인스타 토큰 (Meta 개발자 앱)
1. 인스타 계정을 프로페셔널 계정으로 바꿔요.
2. developers.facebook.com → 앱 만들기 → 사용 사례 **Instagram API**.
3. 앱 대시보드 → Instagram API → **API setup with Unified login (통합 로그인)**.
4. '1. 앱 구성' → **새로운 구성 만들기** → **템플릿으로 만들기** (시스템 사용자 토큰, 만료 없음).
5. '2. 액세스 토큰 생성' → 계정 추가 → **토큰 생성** → 복사 (한 번만 보여요).
6. 계정 이름 아래 숫자(1784…)가 인스타 계정 ID예요.

토큰이 `EAA`로 시작하면 만료가 없어서 연장할 필요가 없어요. `IG`로 시작하는 예전 방식 토큰도 쓸 수 있어요(60일, 자동 연장).

### 3. GitHub
| 종류 | 이름 | 값 |
|---|---|---|
| Secret | `IG_ACCESS_TOKEN` | 위에서 받은 토큰 |
| Variable (선택) | `CARDS_HANDLE` | 카드에 넣을 계정 이름 (예: `@ath.earth`) |
| Variable | `IG_USER_ID` | 인스타 계정 ID (1784…). `EAA` 토큰이면 꼭 필요해요 |

`EAA` 토큰은 만료되지 않아요. `IG` 토큰이면 카드 만들기가 매일 자동으로 연장해요.

### 4. 시험
Actions → **인스타에 올리기** → Run workflow에서 `시험 실행`을 체크하고 실행해요. 계정 이름, 오늘 남은 게시 횟수, 캡션이 나오면 준비 끝이에요.

## 매일 할 일
1. 아침에 Actions → **매일 카드뉴스 만들기**의 최근 실행을 열어요. 요약 화면에 미리보기가 있어요.
2. 괜찮으면 **인스타에 올리기** → Run workflow를 눌러요. 날짜 칸은 비워두면 최신 카드가 올라가요.
3. 문제가 있으면 올리지 않으면 돼요. 그날 카드는 Artifacts에서 내려받아 고쳐 올릴 수도 있어요.

## 카드 디자인 고치기
카드는 **순수 HTML/CSS**예요. 크기는 1080 × 1350 (인스타 4:5)이에요.

```
collector/cards/
  cards.css        스타일 전부 (색·글자 크기·여백). 여기만 고치면 돼요
  design/
    index.html     네 종류를 한눈에 보는 미리보기
    cover.html     1장 · 표지
    topic.html     화제 · 사진 없음 (국기 스티커)
    topic-photo.html 화제 · 사진 있음
    outro.html     마지막 장
  flags/           국기 SVG 20개 (flag-icons, MIT)
  template.mjs     실제 데이터를 넣어 HTML을 만드는 코드
```

1. `design/index.html`을 브라우저로 열어요 (인터넷 연결이 있어야 폰트가 보여요).
2. `cards.css`를 고치고 새로고침하면 바로 확인할 수 있어요.
3. 저장소에 올리면 다음 날 자동으로 만드는 카드부터 같은 디자인이 적용돼요.

색은 `cards.css` 맨 위 `:root`에 모아뒀어요. 예를 들어 형광펜 색은 `--accent`예요.
HTML 구조(태그나 클래스 이름)를 바꿀 때는 `template.mjs`도 같이 고쳐야 해요. 스타일만 바꿀 때는 CSS만 고치면 돼요.

## 장 수
- **자동 게시: 최대 10장** (표지 + 화제 8개 + 마지막 장). Meta API의 캐러셀 한도가 10장이에요.
- **직접 올리기: 최대 20장**. 카드 만들기를 직접 실행하면서 화제 수를 9~18로 넣으면 20장까지 만들어져요. Artifacts에서 내려받아 앱으로 올려주세요.

## 안전장치
- 같은 날짜는 두 번 올라가지 않아요 (`다시 올리기`를 체크해야만 돼요).
- 날짜를 비우고 실행했는데 최신 카드가 이틀 이상 지났으면 올리지 않아요.
- 두 번 연달아 눌러도 동시에 올라가지 않아요.
- 캡션 2,200자, 해시태그 30개를 넘으면 올리지 않아요.
