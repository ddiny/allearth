# 홈 B 국기 자산

- 원본: [lipis/flag-icons v7.3.2](https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3)
- 다운로드: https://codeload.github.com/lipis/flag-icons/zip/refs/tags/v7.3.2
- 라이선스: MIT. 원본 전문을 같은 폴더의 `LICENSE`에 보관한다.
- 수록 범위: `AllEarthGeo.countries`의 국가·지역 코드 250개에 대응하는 4:3 SVG. 원본 벡터를 수정하지 않고 `{id}.svg`로 저장했다. 총 약 1.65MB이며 선택한 국가의 국기만 이미지로 로드한다.
- 사용: `home.html?pins=flags`의 국가명 옆 아이콘. 지구본 동그라미는 홈 A와 같은 이슈 예시 이미지를 유지한다. URL은 기존 타입 B 링크와 호환되도록 유지한다.
- 국기·지역기는 디자인 비교용 아이콘이며 국가·지역 카탈로그의 범위와 표기는 기존 지리 데이터를 따른다.

2026-11-02 로컬 프로토타입에 추가. SVG 파싱 및 250개 카탈로그 코드와 파일의 대응을 검증했다.
