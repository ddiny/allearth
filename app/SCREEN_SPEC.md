# AllEarth HTML 화면 명세

## 2026-11-08 v8 — 기능 반영 기준

- 현재 UI와 승인된 화면 이동을 유지한다. Sue 원본의 다른 카드 배치·독립 Saved 상세·인라인 닉네임·로그아웃 목적지로 교체하지 않는다.
- 기능별 최신 상태: [42개 항목 반영표](docs/SUE_FUNCTION_IMPLEMENTATION_2026-11-08.html). 변경 전 비교 보고서와 구분한다.
- `app-state.js`의 `perform`은 모의 요청 실패 및 저장 예외 시 앱·게시글 상태를 함께 복원한다. Saved 참조를 원본과 분리하여 삭제된 원본 안내와 저장 해제를 지원한다.
- `comments.js`는 Feed 인라인 / My 기존 팝업 / 이슈 댓글에 공통 데이터와 초안·편집·펼침·스크롤을 제공한다. 원댓글+답글 합계를 사용하며 삭제된 부모는 타인 답글이 있을 때 안내로 남는다.
- 작성 위치는 미선택 null과 World를 구분한다. 위치 변경은 적용 전까지 임시 상태이며 취소해도 본문·이미지·태그와 기존 조회 위치가 유지된다.
- 국가 이슈의 Hot/Rising은 시각이 있는 반응 이벤트로 계산한다. Rising 임계값이 없으면 숨긴다. 현재 뉴스 후보와 Today 표시는 편집 예시 데이터 기준이며 실제 운영 집계가 아니다.
- 실제 OAuth·다계정 서버 격리·신고 전송·뉴스 API·운영 계정 삭제·확정 법적 문서는 별도 서비스 연결 범위다.

## 첨부 영역 전체 반영 — 2026-11-08 추가 확정

이번 지정 영역의 MY·Saved·상세 기획과 왼쪽 정책 이미지를 모두 읽고 대조했다. 전체 확인 항목·근거 노드·충돌 적용 기준은 [반영표](docs/MY_SAVED_COVERAGE_2026-11-08.md), 원문은 [텍스트 스냅샷](docs/MY_SAVED_FIGMA_2026-11-08.json)에 있다. 아래의 이전 설명과 다르면 이 절을 적용한다.

- My 활동 요약은 올린 화제 / Saved / 시청내역 순서다. 상단 추가 버튼과 목록의 수정·삭제 버튼을 제공한다. 격자에도 태그·조회·반응 수를 표시한다.
- 설정과 프로필의 닉네임 변경은 팝업이며, 취소/완료 후 원래 화면으로 복귀한다. 로그아웃·탈퇴는 실패 시 계정을 유지하고 재시도하며, 성공하면 로그인 화면으로 이동한다. `?fail=logout|withdraw`로 최초 실패를 재현한다.
- My 작성·수정은 기존 작성기를 iframe으로 재사용한 바텀시트다. 저장·취소 후 My의 보기·스크롤로 돌아온다. 일반 Feed는 기존 독립 작성기를 유지한다.
- Saved 탭 순서는 국가 / 게시글이며, 후속 사용자 요청에 따라 첫 진입은 게시글을 보여준다. 저장 콘텐츠가 없는 새 모의 세션에는 이미지 게시글 3개와 국가 3개를 한 번 추가한다. 기존 저장 내역·저장 해제·이후 선택 탭은 보존하며 빈 상태·오류 예시와 비로그인에는 자동 추가하지 않는다. 저장 콘텐츠(게시글·수집 이슈)는 합계 100개 제한, 국가 수는 별도다. Feed·My·이슈 저장을 동일 API로 검사하며 한도 초과 시 기존 데이터를 삭제하지 않는다.
- My/Saved 각각의 예시·빈 상태·오류와 국가 시트·이슈 상세의 연결을 제공한다. 선택 이슈 ID를 URL에 전달해 Saved·시청내역에서 정확한 제목으로 다시 연다.
- 후속 Saved UI 수정: 국가는 국기 위/국가명 아래의 3열 카드, 게시글은 이미지·본문 14px·태그·통계가 있는 2열 카드다. 카드와 별개의 하단 저장 해제 버튼은 최소 44px이며 목록 제목·개수와 정렬 안내를 함께 표시한다. 긴 국가명은 한 줄 말줄임하되 title과 링크 접근성 이름으로 전체 이름을 보존한다.
- 국가 시트는 3개 이슈를 표시한다. 기존 자료 1개와 추가 편집 예시를 구분하며, 순위는 예시다. 9개 대표 도시의 현지 시간은 `Intl.DateTimeFormat`으로 표시하고 그 외 국가는 정보 없음 상태를 제공한다.
- Feed는 반응별 수와 저장·댓글 수를 표시한다. 실제 작성 시각은 날짜로, 기존 순번형 샘플은 “예시 기록”으로 구분한다. 타인 글 메뉴의 신고는 사유·취소·실패 재시도·모의 완료를 제공하며 서버로 전송하지 않는다.

## MY·공통 메뉴 — 2026-11-08

이번 절은 아래 11월 6일의 My=시청내역 및 작성 바텀시트 설명보다 우선한다. Figma `ㄴ 하반기`의 MY 원본, 상세 기획, `화면정의_1101` My 01~06과 정책 메모를 대조해 HTML에 반영했다. Figma 원본은 편집하지 않았다.

- **게시글이 있는 프리뷰:** `my-posts-grid` / `my-posts-list`는 `my.html?example=posts&view=grid|list`로 연결한다. 로컬 SVG 일러스트가 있는 글 4개와 텍스트 글 2개를 한 번 추가한다. 기존 글을 덮어쓰지 않으며 샘플 수정·삭제도 유지한다. 초기화하면 샘플을 다시 생성한다.
- **프리뷰 로그인 상태:** 왼쪽 화면 선택에서만 `previewAuth=in|out`으로 모의 상태를 지정하고 URL에서 즉시 소비한다. 로그아웃 예시 뒤 프로필·격자·목록·설정·시청내역·Saved로 이동할 수 있다. 앱 하단 이동에는 이 플래그를 붙이지 않아 실제 모의 로그아웃 상태를 유지한다.

- **공통 메뉴:** Earth / Feed / Saved / My의 아이콘·라벨·활성 상태·터치 영역을 `app-shell.js/css`에서 공유한다. My는 프로필/내 피드이며 시청내역은 My의 하위 화면이다. Saved는 Earth의 국가/수집 이슈와 Feed의 개별 게시글을 모아 표시한다.
- **공유 데이터:** `app-state.js`는 브라우저 탭의 모의 계정·닉네임·저장·열람 기록을 관리한다. 같은 탭에서 페이지를 이동해도 유지하며, 실제 인증·서버 저장이나 다른 사람의 데이터에는 연결하지 않는다.
- **내 피드:** 기본 격자, 최신순의 본인 게시글만 표시한다. 작은 화면에서는 2열, 일반 화면에서는 3열이다. 목록 전환 및 선택한 글 위치 이동, 작성·수정·삭제, 게시글 수 갱신을 제공한다.
- **닉네임:** 프로필 인라인 편집을 적용한다. 정책 메모의 1~10자, 한글/영문/숫자/밑줄, 앞뒤 공백 제거, 내부 공백 금지, 대소문자 구분 없는 샘플 중복 검사를 가입/수정에서 공유한다. 서버 중복 검사는 구현 범위가 아니다.
- **시청내역:** 수집 이슈 상세와 실제 표시된 게시글 본문을 기록한다. 최근 열람순 최대 100개, 중복 제거·재열람 갱신, 유형별 탭, 삭제된 글의 접근 불가 상태를 제공한다.
- **설정·계정:** 읽기 전용 Google 계정, 약관/개인정보 안내, 로그아웃·탈퇴 확인을 제공한다. 종료 후 My 비로그인 화면으로 이동한다. 실제 정책 원문이 없으므로 정책 화면은 데모임을 명시하며 법적 문서를 새로 작성하지 않았다. 탈퇴는 이 탭의 샘플 데이터만 정리한다.
- **공통 작성기:** Feed 07의 독립 화면을 적용하고 하단 메뉴를 숨긴다. 본문·World 아닌 위치·해시태그 1개(1~19자)가 필수다. 이미지는 선택, 최대 10개, 파일당 8,000,000 bytes 이하 JPG/PNG/WebP를 허용한다. 첨부는 로컬 미리보기용으로 축소해 보관하며 원본 업로드가 아니다. 수정·취소·오류 후 입력과 출발 화면을 보존한다.

서로 다른 문서 정의의 적용 기준: 닉네임 진입/로그아웃 목적지/독립 작성기는 My 01~06 및 Feed 07, 닉네임 제약은 구체적인 정책 메모를 적용했다. 탈퇴 데이터 처리는 My 05를 샘플 세션에 한정해 재현한다. 운영 서비스의 실제 보관·삭제 정책과 약관 URL은 별도 확정이 필요하다.

주요 파일: `my.html/js/css`, `saved.html/js/css`, `app-state.js`, `app-shell.js/css`. 실행 진입점은 기존 `preview.html`이다.

## 홈 3D 지구본 확장 · 2026-10-20

사용자 승인에 따라 이전 2D 지형 배치를 3D 뷰포트로 대체했다. Figma 기반 상단 검색·국가명·하단 메뉴는 기존 토큰을 재사용한다. `preview.html`은 홈을 기본 선택한다.

CSS 배율 대신 실제 카메라 거리를 사용하며 홈 A/B 공통이다.
- 줌 컨트롤: right 16px / bottom 170px, 각 버튼 44px. 작은 화면은 right 12px / bottom 148px.
- 줌 모션(2026-11-02): 버튼·키보드·휠은 하나의 카메라 애니메이션을 공유한다. 로그 고도의 임계 감쇠(응답 계수 19/s, 약 250ms에 목표 변화의 95%)로 부드럽게 시작하고 멈춘다. 후속 피드백에 따라 기존 약 300ms에서 조금 빠르게 조정했다. 같은 방향 연속 입력은 목표에 누적하고 반대 입력은 현재 고도를 기준으로 방향을 바꾼다. 휠은 250px를 버튼 한 단계로 정규화한다. 국가 이동·전체 보기·한국 복귀·드래그·리사이즈는 이전 카메라 모션을 중단하며, 동작 줄이기에서는 즉시 이동한다. 핀치는 기존 OrbitControls 경로와 거리 제한을 유지한다.

## 화면 그룹·홈 타입 비교 · 2026-11-02
