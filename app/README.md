# AllEarth 앱 화면 프로토타입

## 2026-11-08 v8 — 현재 UI 유지, Sue 기능 반영

현재 화면 배치·색상·4개 메뉴를 유지하고 누락 기능을 연결했습니다. **저장 해제 실패 후 카드·탭·스크롤 유지 및 재시도**, **댓글 초안 보존**, 댓글/답글·수정/삭제, World 작성·위치 적용/취소, 이미지별 오류 처리, Earth 통합 검색·시트 확장·이슈 반응을 제공합니다.

실행은 `preview.html`을 열면 됩니다. [42개 항목 반영 결과와 확인 방법](docs/SUE_FUNCTION_IMPLEMENTATION_2026-11-08.html)을 함께 확인하세요. 이전 기능 비교 보고서는 변경 전 기록이며, 현재 상태는 이 반영표와 `qa/VALIDATION.md`의 최신 절을 기준으로 합니다.

기존 Saved→Feed 본문/국가 시트→Saved 복귀, My 작성 바텀시트·닉네임 팝업·로그아웃 후 로그인 화면을 유지합니다. 로컬 Chrome의 HTTP 및 `file://` 실행을 검증했습니다. 실제 인증·서버 게시·신고·실시간 뉴스·운영 계정 삭제는 연결하지 않은 프로토타입입니다. Rising 운영 기준과 확정 약관 원문은 별도 제공이 필요합니다.

Saved UI 후속 수정: 국가 카드는 국기와 이름을 세로로 배치하고, 게시글은 본문을 읽기 쉬운 2열 카드로 표시합니다. 각 카드의 저장 해제 버튼과 목록 개수·정렬 안내를 정리했습니다. 320/390/430px 및 로컬 파일 실행을 검증했습니다.

## 2026-11-08 첨부 MY·Saved 전체 기획 반영

My의 상단 추가·게시글 수정은 바텀시트로 열립니다. 설정에서는 닉네임 변경 팝업, 로그아웃·탈퇴 확인과 실패 재시도를 확인할 수 있습니다. 완료하면 로그인 화면으로 이동합니다. 일반 Feed 작성은 독립 화면을 유지합니다.

Saved는 **국가 / 게시글** 탭이며, 처음 열면 게시글을 바로 보여줍니다. 저장 콘텐츠가 없는 새 모의 세션에는 이미지 게시글 3개와 국가 3개를 한 번 추가하며, 기존 저장 내역과 저장 해제는 유지합니다. 프리뷰에서 저장 예시·빈 상태·오류 상태도 선택할 수 있습니다. 저장 콘텐츠는 최대 100개입니다. 국가를 열면 공통 이슈 시트로, 게시글을 열면 본문으로 이동하고 Saved로 복귀합니다.

국가 시트의 이슈 목록·현지 시간·예시 순위와 상세의 관련/다음 이슈, Feed의 반응별 수·게시 날짜·신고 모의 흐름을 연결했습니다. 확인한 전체 항목과 설명 차이의 적용 기준은 [반영표](docs/MY_SAVED_COVERAGE_2026-11-08.md)에 있습니다. 이전 설명과 차이가 있으면 이 절을 우선합니다.

## 2026-11-08 업데이트: MY와 메뉴 연결

`preview.html`에서 **My** 그룹을 선택하거나 `my.html`을 직접 여세요. 프로필·내 피드·닉네임 수정·설정·시청내역·로그아웃/탈퇴 흐름을 확인할 수 있습니다. **Saved** 그룹은 국가와 콘텐츠 저장을 통합합니다. Earth / Feed / Saved / My 하단 메뉴와 저장 상태를 페이지 사이에서 공유합니다.

My의 **게시글 격자 / 게시글 목록** 버튼으로 샘플 게시글 6개가 있는 화면을 확인하세요. 이미지가 있는 글, 텍스트 글과 여러 이미지 넘기기를 제공합니다. 샘플은 한 번만 추가하며 기존 작성 글과 수정·삭제 내용은 유지합니다. 화면·테스트 초기화 시 다시 시작합니다.

왼쪽에서 **로그아웃** 예시를 선택한 뒤 다른 화면을 누르면 해당 화면의 모의 로그인 상태로 전환합니다. 앱 내부 설정에서 로그아웃한 경우에는 하단 메뉴 이동·새로고침 후에도 비로그인 상태가 유지됩니다.

작성기는 본문·위치·해시태그 검증과 이미지 첨부를 지원합니다. My에서는 바텀시트로, 일반 Feed에서는 독립 화면으로 열립니다. 닉네임은 가입/수정 모두 1~10자 및 동일 문자 규칙을 사용합니다. 상세 적용 기준은 `SCREEN_SPEC.md`의 11월 8일 절을 참고하세요.

이번 버전은 브라우저 탭의 모의 계정으로 시작합니다. 글·저장·열람 기록은 같은 탭에서 유지됩니다. 로그인/탈퇴는 실제 계정 처리가 아니며 서버로 게시하지 않습니다. ZIP에는 팀원이 브라우저에서 입력한 데이터가 포함되지 않습니다.

HTML·CSS·JavaScript로 로그인 A/B, 가입, 내 지구, 국가 이슈와 지역 Feed를 확인하는 프로토타입입니다. Figma 원본은 수정하지 않고 HTML에서 동작을 검토합니다.

## 열기와 확인

- **현재 시작 화면: `preview.html` → My 프로필.** Feed 그룹에서 지역 Feed 목록 / 지역 Feed 그리드를 선택합니다. `feed.html?region=seongsu&view=list` 또는 `feed.html?region=seongsu&view=grid`로 앱만 열 수 있습니다.
- 지역 카드를 선택하면 같은 위치·정렬의 전체 본문 목록에서 선택한 글을 보여 줍니다. 뒤로 가면 원래 보기·스크롤로 돌아옵니다. 지역 저장은 제공하지 않으며, 개별 글 저장은 Saved에 모입니다. 작성과 반응은 브라우저 탭 안에서만 유지합니다.
- **이슈 → 화제 디테일**은 기존 국가 뉴스 예시입니다. 홈의 국가 이슈 제목을 선택하면 해당 화제를 열고 뒤로 기존 시트에 복귀합니다. 예전 성수동 단독 주소 `topic.html`은 새 지역 Feed로 연결됩니다.
- Windows에서는 `프로토타입_열기.cmd`를 더블클릭합니다. `preview.html`이 열립니다.
- 또는 `preview.html`을 브라우저에서 열어 테스트 도구와 함께 봅니다.
- **이슈** 그룹에서 Figma의 국가 이슈 시트를 확인합니다. `preview.html?screen=issue` 또는 `home.html?view=issue`로 바로 열 수 있습니다. 홈 A/B의 국가·이슈 동그라미에서도 연결됩니다. 국가/이슈 저장, 이야기 추가와 기록은 로컬 미리보기에서만 유지됩니다.
- `index.html`은 로그인 A, `index-b.html`은 로그인 B를 테스트 도구 없이 각각 여는 파일입니다.

브라우저 정책이나 배포 환경에 가깝게 확인하려면 이 폴더에서 아래 명령을 실행한 뒤 `http://127.0.0.1:4173/preview.html`을 엽니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

`preview.html`은 My 프로필로 시작합니다. `로그인 / 가입 / 홈 / 이슈 / Feed / Saved / My`에서 화면을 선택합니다. Feed에는 목록·그리드·World를 제공합니다. 화면 그룹을 오가면 해당 그룹에서 마지막으로 선택한 타입으로 돌아갑니다. 320 × 568, 390 × 844, 430 × 932 크기와 이벤트 로그로 확인할 수 있습니다. 홈은 `preview.html?screen=home`, 국가 이슈는 `preview.html?screen=issue`로 바로 열 수 있습니다. 로그인 분기 테스트는 로그인 화면에서만 표시합니다.

홈 B를 직접 미리보려면 `preview.html?screen=home-flags`, 앱 화면만 보려면 `home.html?pins=flags`를 엽니다. 현재 타입은 프리뷰 주소에 반영되므로 새로고침해도 유지됩니다. `앱 화면만 열기`와 초기화도 현재 타입을 따릅니다.

모의 신규 로그인은 로그인 A/B → 가입 정보 → 가입 완료 → 내 지구 홈으로 이동합니다. 기존 회원은 로그인 완료를 거쳐 같은 홈으로 이동하고, 취소·실패는 로그인 화면에 남습니다. 화면 전환은 iframe 안의 페이지가 직접 처리합니다. 로그인 유형·가입 정보·홈을 직접 선택하면 이벤트 로그를 비우며, 자동 이동 과정의 로그는 보존합니다. 초기화 버튼은 현재 단계와 선택한 크기를 유지한 채 화면과 로그를 초기화합니다.

화면 안의 Google 버튼·이용약관·개인정보 처리방침을 눌러 보세요. 로그인 A에는 닫기 버튼도 있습니다. 홈에서는 지역 검색·국가 핀·랜덤 이슈·Keep·하단 메뉴를 확인할 수 있습니다. 이벤트 로그는 `auth.requested`, `auth.preview_succeeded`, `auth.returning`, `auth.cancelled`, `auth.failed`, `signup.completed`, `signup.cancelled`, `complete.entered`, `country.selected`, `home.search`, `home.random`, `home.recenter`, `home.nav`, `home.keep`, `legal.requested`를 표시합니다. Google 버튼은 700ms 로딩과 중복 클릭 방지만 재현합니다.

## 현재 범위

현재 구현은 Figma 로그인 A/B·가입 정보·내 지구 홈과 토큰 기반 완료 화면의 시각·클릭 흐름 확인용입니다. A에는 닫기 버튼이 있고 B에는 없습니다.

- Google 로그인 성공은 실제 Google OAuth가 아닌 모의 분기입니다. 계정·세션은 생성하지 않습니다.
- 공개 사용자명은 선택 입력이며 영문 소문자·숫자·`_` 4~16자 형식만 확인합니다. 서버 고유성 확인과 저장은 하지 않습니다.
- 닉네임은 앞뒤 공백을 제거한 뒤 2~12 grapheme(눈에 보이는 글자 단위)을 필수로 확인합니다. 입력값은 브라우저에 저장하지 않습니다.
- 개인정보 수집·이용과 연령 확인은 필수 체크 두 개와 전체 동의 상태만 모의로 처리합니다. `보기`는 원문 대신 프로토타입 안내 모달을 열며, 실제 동의를 기록하지 않습니다.
- 이용약관과 개인정보 처리방침의 원문·동의 처리는 연결하지 않았습니다.
- 로그인 A의 닫기 버튼은 이전 화면 또는 홈으로 이동하지 않고 `login.dismiss` 이벤트만 발행합니다.
- 홈은 Globe.GL 기반의 실제 3D 지구본입니다. 전 세계 국가·지역 검색과 국가 경계는 로컬 데이터로 작동합니다. 주요 9개 국가 핀에 2026-11-02 기준 이슈 이미지 예시를 넣었으며 클릭하면 주제·일정·이미지 출처를 볼 수 있습니다. 일부 이미지는 표시된 자료 사진이며 실시간 인기 순위·뉴스 API·위치 정보는 연결하지 않았습니다. [이슈와 이미지 출처](assets/topics/SOURCES.md)를 참고하세요.
- Keep은 페이지를 떠나면 사라지는 메모리 상태이며, 하단 메뉴는 범위를 설명하는 간단한 패널입니다.

별도 로그인 아이디가 필요한지에 관한 제품 검토는 [GOOGLE_SIGNUP_FLOW.md](GOOGLE_SIGNUP_FLOW.md)를 참고하세요.

## 점진적 확장 제안

다음 실제 기능을 추가할 때는 화면 하나당 HTML, 화면 CSS, 화면 JavaScript를 추가하고 공통 요소만 `tokens.css`와 공용 스타일로 올립니다. 현재 화면 간 연결은 모의 이벤트와 location 이동으로 확인하며, 준비된 시점에 서비스 어댑터와 라우터를 연결합니다.

1. 실제 OAuth 콜백과 서버 검증을 추가하고, 모의 `scenario` 분기를 제거합니다.
2. 사용자명 고유성 확인·계정 생성·동의 기록을 서버 API로 구현합니다.
3. 홈의 국가·이슈·Keep을 API와 영속 저장소에 연결하고, 위치 기능은 별도 동의 흐름으로 설계합니다.
4. 색상·타이포·간격처럼 여러 화면이 공유하는 값만 의미 토큰으로 유지합니다.
5. 화면 코드가 서비스 SDK나 API 세부 사항을 직접 알지 않도록 하여, 목업 흐름에서 실제 서비스로 교체할 때 UI를 유지합니다.

위 구조는 향후 계획입니다. 현재의 가입 성공·기존 회원 완료·홈 이슈는 실제 인증이나 실시간 데이터를 뜻하지 않으며, 서비스 어댑터·라우터·실제 인증은 아직 구현되어 있지 않습니다.

네이티브 기기와 실제 인증은 검증 범위 밖입니다. 로컬 Chrome에서 `file://` 직접 실행과 HTTP를 검증했습니다. 회사 브라우저 정책으로 직접 열기가 제한되면 위 HTTP 방법을 사용하세요. HTTP 미리보기는 로컬 서버가 실행 중일 때 사용할 수 있습니다.

## 3D 지구본 조작

- 드래그: 상하좌우 회전. 자동 회전과 자유 이동(pan)은 끈다.
- 핀치 / 마우스 휠 / 오른쪽 `＋`·`−`: 같은 확대 범위로 조작한다.
- `전체 보기`: 보고 있는 방향을 유지하며 첨부 기준과 같은 홈 기본 크기까지 축소한다. 이 크기가 최대 줌아웃이며 버튼·휠·키보드·핀치로 더 작아지지 않는다. 홈 A/B에 공통 적용한다.
- 하단 원형 버튼: 대한민국·동아시아의 크게 표시된 초기 보기로 돌아간다. 390 × 844에서 지구 지름은 원본 캡처와 같은 약 480px이며, 짧은 화면에서는 가용 높이에 맞춘다. 기기 위치를 요청하지 않는다.
- 국가 면 / 마커 / 검색: 국가를 선택하고 해당 위치로 이동한다. 검색창을 누르면 전체 250개 국가·지역이 열리고 입력하면 같은 목록에서 즉시 필터링된다. 하단 탐색도 이 검색창으로 연결된다.
- 이슈 동그라미는 회전·줌·화면 크기에 맞춰 간격을 유지하며, 국가 좌표에서 이동한 경우 얇은 연결선으로 위치를 표시한다.
- 홈 B는 국가명 옆 아이콘만 해당 국기로 표시한다. 지구본 위 동그라미에는 홈 A와 같은 이슈 예시 이미지를 유지한다. 국가 선택·검색·회전·줌·전체 보기·이슈 상세·Keep도 같은 동작을 공유한다. 국기 출처는 [assets/flags/SOURCES.md](assets/flags/SOURCES.md)에 있다.
- 방향키, `+`, `-`, `Home` 키를 지원한다. 검색과 전체 국가 목록은 지구본 드래그 없이도 사용할 수 있다.
- 작은 국가·지역 및 데이터상 별도 경계가 없는 지역도 검색과 좌표 이동을 제공한다. 국가명·영문명·ISO 코드·별칭으로 검색할 수 있다.
- 사용자 시스템의 `동작 줄이기` 설정을 존중한다. WebGL을 사용할 수 없는 환경에서도 국가 검색과 목록은 유지한다.

Geography는 [Natural Earth](https://www.naturalearthdata.com/)와 [mledoze/countries](https://github.com/mledoze/countries) 기반이다. 데이터 범위·가공·라이선스는 [지리 데이터 출처](assets/geo/SOURCES.md)를 참고한다. 국가·지역 카탈로그와 국가 경계의 행 수는 서로 다르며, 경계 없는 지역은 대표 좌표로 보완한다. 세계 개요·국가 탐색용이며 거리·건물 수준의 지도는 아니다.

라이브러리·데이터·폰트는 모두 상대 경로의 로컬 파일이다. CDN, API 키, 애플리케이션 빌드, 실행 중 지형 다운로드가 필요 없다. 현재 파일을 다른 곳으로 옮길 때는 `preview.html` 하나가 아니라 `allearth-app-prototype` 폴더 전체를 함께 옮긴다.
