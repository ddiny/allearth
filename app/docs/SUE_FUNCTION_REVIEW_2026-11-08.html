현재 UI를 유지하며 먼저 보완할 기능

  1. 실패와 초안 보존: 저장 해제 실패 시 원복, 미전송 댓글 유지·폐기 확인, 게시글 삭제 실패 재시도.
  2. 공통 댓글·답글: 최신/인기 정렬, 댓글 좋아요, 답글 5개씩 조회, 본인 댓글 수정·삭제, 삭제 원댓글 안내. Earth와 Feed가 같은 모델을 사용해야 합니다.
  3. World 작성 위치: World와 미선택 null을 구분하고 위치 임시 선택→적용/취소→작성 상태 복원을 연결합니다.
  4. Earth 탐색: 이슈 키워드 검색, 시트 Half/Full, 후보·뱃지 규칙, 관련 이슈의 0/1개 예외 처리를 보완합니다.
  5. Saved 접근 불가 원본: 원본이 삭제돼도 저장 항목을 안내 카드로 유지하고 해제할 수 있어야 합니다.

실제 OAuth, 서버 저장·집계·신고 전송은 별도 서비스 연결 범위입니다. 댓글 모델·World 위치·로컬 실패 복원처럼 서버 없이도 검토 가능한 동작은 기능 공백으로 구분했습니다.
