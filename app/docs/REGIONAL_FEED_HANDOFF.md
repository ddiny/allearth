# 지역 Feed HTML 작업 인계 — 2026-11-06

## 현재 정본과 실행

사용자 정정: **Figma 원본을 수정하지 않는다. 화면·플로우 변경은 HTML에 구현한다.**

- 기존 `allearth-app-prototype/preview.html`이 최신 프리뷰다. 더블클릭하면 지역 Feed 목록부터 시작한다.
- 프리뷰의 **Feed → 지역 Feed 목록 / 지역 Feed 그리드 / World Feed / Saved**를 선택한다.
- 단독 화면: `feed.html?region=seongsu&view=list`, `feed.html?region=seongsu&view=grid`.
- 앱의 첫 Feed 진입은 `feed.html`의 World다. 프리뷰는 첨부 시안 검토를 위해 성수동을 명시해 연다.
- `프로토타입_열기.cmd`는 기존대로 preview.html을 연다. 예전 성수동 단독 `topic.html`도 새 Feed로 연결된다.

## 구현한 화면과 흐름

1. 목록은 왼쪽 썸네일·작성자·시각·본문 2줄·태그·조회/좋아요, 그리드는 같은 결과의 2열 이미지 카드다. 이미지 없는 글은 텍스트 카드다.
2. 목록/그리드 전환은 위치·정렬을 유지한다. 화제순은 좋아요+Saved+댓글+반응 합계, 동률 최신순이다. 최신순은 생성 시각 내림차순이다.
3. 카드 선택은 같은 결과의 전체 본문 연속 목록으로 전환한다. 선택한 글을 헤더 바로 아래에 맞추고 앞뒤 글을 볼 수 있다. 뒤로는 원래 탭·보기·정렬·지역·스크롤로 복귀한다.
4. 지역 자체 저장은 없다. 개별 글 저장은 Saved에서 확인한다. Earth의 기존 국가·뉴스 저장은 그대로 유지한다.
5. 위치 선택 적용 시 지역·화제순·상단으로 진입하고 마지막 목록/그리드 보기는 유지한다. 취소는 기존 상태를 유지한다.
6. 작성은 현재 지역을 기본값으로 실제 입력한다. 취소 확인/계속 작성, 등록 후 원래 상태 복귀를 지원한다. 다른 지역에 등록해도 조회 지역은 유지하며 화제순 맨 위에 새 글을 강제로 넣지 않는다.
7. 좋아요·개별 글 Saved·댓글·반응·내 글 수정/삭제를 모든 보기에서 공유한다. 내 글의 지역을 현재 필터 밖으로 수정하면 원래 목록으로 돌아간다.
8. My에는 전체 본문 화면에서 작성자 영역을 실제 확인한 글만 기록한다. 요약/그리드 노출은 이력에 추가하지 않는다.
9. Earth/Feed/Saved/My 탐색과 빈 결과/오류·재시도를 연결했다. 기존 Earth 국가 이슈→뉴스 상세는 유지한다.

## 데이터 및 검증 범위

- 샘플 데이터와 브라우저 탭의 sessionStorage로 동작한다. 실제 서버·계정·사진 업로드·게시·실시간 뉴스 연결은 없다. 저장소에는 사용자가 입력한 내용이 들어가지 않는다.
- 참고 캡처처럼 이미지 블록은 그라데이션 예시다. 실제 지역 사진으로 오인될 다른 국가 뉴스 사진은 사용하지 않는다.
- 글/반응은 같은 브라우저 탭에서 유지한다. 새 탭/다른 컴퓨터로 샘플 변경 내용이 이동하지 않는다. 프리뷰의 초기화 버튼은 Feed 샘플 상태를 초기화한다.
- Chrome의 file:// 실행에서 12개 실제 브라우저 테스트 묶음을 통과했다. 목록/그리드 동일 순서, 전체 본문 앵커·뒤로 스크롤, 위치 취소, 작성 취소 확인, Hot/New 등록, 다른 지역 게시, Saved/My, 수정 후 필터 이탈, 안전한 입력 표시, Empty/Error 재시도, query/reset, 프리뷰 그룹 복귀와 기존 주소 연결을 확인했다.
- 320×568, 390×844, 430×932에서 가로 넘침 없이 표시됨을 확인했다. 런타임 JavaScript 오류 0건. 캡처는 `qa/feed-list-*.png`, `qa/feed-grid-*.png`, `qa/feed-preview-20261106.png`.
