Sue Figma 기능 반영 결과 · v8

기존 색상·타이포·카드 배치·4개 메뉴·승인된 이동 흐름을 유지하고 누락 동작만 추가했다. 원본 Figma는 변경하지 않았다.

기준 Figma · 변경 전 42개 항목 검토 · 프로토타입 열기

확인 방법

My 게시글 목록에서 댓글 입력 → 닫기 → Saved 이동 → My 댓글 재진입으로 초안 보존을 확인할 수 있습니다. 저장 실패는 저장 해제 실패 예시에서 저장 해제 → 오류 → 다시 시도를 확인하세요. 각 실패 예시는 한 페이지에서 한 번 실패합니다.

새 댓글 기능은 Feed 본문·My 댓글·이슈 상세에서 사용할 수 있습니다. 답글이 5개보다 많으면 단계별 더보기가 나타납니다.

이 버전은 브라우저 탭의 단일 모의 계정과 예시 데이터입니다. 실제 로그인·서버 게시·신고·계정 삭제·실시간 뉴스는 연결되지 않았습니다. Rising 운영 임계값과 확정 정책 문서는 별도 입력이 필요합니다. ZIP에는 팀원의 브라우저 입력 데이터가 포함되지 않습니다.
